**HotShop** is an online marketplace application that allows users to buy and sell items through a simple and accessible platform.

## About HotShop

HotShop is developed as part of the CS3227 software engineering project.

The project focuses on building a production-level marketplace application while applying software engineering practices such as automated testing, continuous integration, documentation, and agent-assisted software development.
